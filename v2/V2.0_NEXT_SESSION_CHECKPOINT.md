# FRAME ATLAS v2.0 — 다음 작업 재개 체크포인트

기록일: 2026-10-14 (KST)
개발 브랜치: `FRAME_ATLAS-v2.0-development`
운영 브랜치 `main` 및 공개 사이트는 수정하지 않았다.

## 사용자 요청 범위
1. 기존 서울·경기·인천 장소 유지.
2. 대형 촬영 스튜디오·공연장·프로덕션 공간 추가.
3. 영화·드라마·광고 촬영 이력이 있거나 촬영 적합성이 높은 장소 추가.
4. 세계적 건축가의 건축물 및 예술적 조형물 추가.
5. Museum SAN(뮤지엄 산)은 예술·건축 가치가 높으므로 후보에서 제외하지 않고 포함 방향으로 검토.
6. 전국으로 확대.
7. 메인 지역 선택을 서울, 경기·인천(수도권), 강원권, 충청권, 전라권, 경상권, 제주권으로 구분.
8. 이미지 정책: 실제 장소와 일치하는 이미지라면 먼저 장소 참고 이미지로 활용할 수 있다. 다만 대표사진 선정은 나중에 별도 판단한다. 장소-이미지 일치 자체가 확인되지 않은 사진은 확인된 사진처럼 보이지 않게 한다. 사진 권리와 상업 촬영 허가는 별도 확인 항목이다.

## 확인된 상태 (2026-10-14 최신 브랜치 재확인)
- 현재 개발 브랜치의 최신 데이터는 활성 장소 58개, 검토 후보 9개다. 이전 33개/14개 수치는 오래된 조사 시점이므로 현재 수치로 덮어쓴다.
- 메인 화면에는 7개 권역 키(`seoul`, `capital`, `gangwon`, `chungcheong`, `jeolla`, `gyeongsang`, `jeju`) 바로가기가 있고, `regionGroupKey`, `regionMatches`, `syncRegionFilters`가 구현돼 있다. 단, 모든 화면과 실제 브라우저에서 검증됐다고 간주하지 않는다.
- 레거시 `data/places.js`는 GitHub 조회 응답상 0바이트다. 레거시 v5.44가 이 데이터로 정상 작동한다고 가정하지 않는다.
- `v2/data/places.json`에는 최신 조회 기준 활성 장소 58개, 검토 후보 9개가 있다.
- 검토 후보에는 Museum SAN(`nat-museum-san`, 강원), F1963(`nat-f1963`, 부산), 국립아시아문화전당(`nat-acc-gwangju`, 광주), LG아트센터 서울, 리움미술관 등이 있다.
- v2는 `selectionRubric`, `reviewQueue`, `excludedLocationIds`를 이미 사용한다. 기존 구조를 먼저 보완하고 운영판에 급히 섞지 않는다.
- 권역 매핑은 `REGION_GROUPS`, `regionGroupKey`, `regionMatches`, `syncRegionFilters`를 통해 목록·홈·지도·분석·검토 후보 필터에 연결되어 있다. 브라우저 회귀 테스트에서 실제 동작 확인이 남아 있다.
- `V2.0_DEVELOPMENT_AND_RECOVERY_PLAN.md`에 개발 원칙과 필수 테스트 기준이 기록돼 있다.

## 반드시 지킬 원칙
- 연결이 끊겨도 이 문서와 최근 커밋을 먼저 확인하고 여기서부터 재개한다. 계획 조사부터 반복하지 않는다.
- 운영판을 삭제하거나 수정하지 않는다.
- 데이터 수정 전 원본을 보존하고, 데이터·UI·서비스워커 캐시 버전·테스트를 한 변경 단위로 갱신한다.
- 장소에는 고유 ID를 유지한다. 이름으로 삭제/덮어쓰기하지 않는다.
- 후보를 활성 장소로 올리기 전 장소 실재, 위치, 사진 일치, 촬영 적합성 상태를 기록한다.
- 이미지 상태는 최소한 장소 일치/참고 이미지/대표 선정 대기/대표 승인으로 분리한다. 사진이 장소와 일치한다면 참고 이미지로 우선 사용할 수 있지만, 대표사진 승인은 별개다.
- 테스트를 실제로 실행하지 못하면 통과했다고 보고하지 않는다.

5. PC·모바일 브라우저 회귀 테스트를 실행하고 결과를 문서화한다. 실제 실행 전에는 통과 처리하지 않는다.
6. 모든 검증 전에는 공개 운영판에 반영하지 않는다.

## 최근 실제 확인
- Museum SAN(`nat-museum-san`)은 활성 장소 데이터에 포함되어 있다. 장소 일치가 확인된 워터가든/아치웨이 참고 이미지 후보가 연결되어 있으며 `primaryImageId: null`, 대표사진 미선정 상태다. 이미지 권리는 미확인이고 상업촬영 허가는 별도 문의하도록 기록되어 있다.
- F1963(`nat-f1963`)도 활성 데이터에 있으며 부산의 재생 산업·문화공간 후보로 기록되어 있다. 사진 권리와 촬영 허가는 별도 확인 상태다.
- 기존 권역 필터 로직과 7개 권역 버튼은 소스에서 확인했지만, 이 세션에서 Playwright 브라우저 테스트를 실제 실행하지는 않았다.
