# FRAME ATLAS 2.0 — 촬영지 보강 1차 검토표
작성: 2026-10-15

## 상태와 제한
- 이 문서는 2.0 후보 선별의 작업 결과이며, 현재 장소 데이터와 구버전 214곳의 실제 대조 완료를 뜻하지 않는다.
- 확인 결과 `casio8000/FRAME_ATLAS_v2.0` 저장소는 비어 있다. 운영 저장소 `casio8000/FRAME_ATLAS`의 `data/places.js`도 GitHub 파일 API에서 내용이 빈 문자열로 반환되어, 현재 2.0의 장소 ID·목록을 신뢰성 있게 비교할 수 없다.
- 따라서 아래 항목을 ‘누락 확정’으로 표시하지 않는다. 중복 여부를 확인하기 위한 후보 목록으로 저장한다.

## 예술적 촬영 후보 — 중복 확인 후 반영 검토
### 건축·미술·공간
- 뮤지엄 SAN (원주): 안도 다다오 건축, 물·돌·빛·기하학적 프레임
- 동대문디자인플라자 DDP (서울): 곡면 금속 외피, 야간 조명, 도시적 패션 컷
- 국립현대미술관 서울관 (서울): 중정·벽돌·현대미술 공간
- 리움미술관 (서울): 건축과 조각·전시 공간의 조합
- 서울공예박물관 (서울): 전통 재료·현대적 전시 공간
- 문화비축기지 (서울): 산업 구조물, 콘크리트·탱크 공간
- 서울식물원 온실 (서울): 대형 유리 구조, 식물·습도감 있는 실내 프레임
- 노들섬 (서울): 공연·건축·한강 풍경을 함께 구성할 수 있는 복합 공간
- 플랫폼엘 컨템포러리 아트센터 (서울): 현대 건축과 전시 공간
- 서울웨이브 아트센터 (서울): 수변 건축과 한강 반영

### 대형 촬영 스튜디오·제작 시설 — 운영·대관 확인 필수
- 남양주 종합촬영소/남양주 촬영 관련 시설: 세트·야외 촬영 인프라의 현재 운영 및 접근 가능 여부 확인
- 한국영상자료원·영상 제작 관련 시설: 일반 촬영 장소로 개방되는지 확인 후에만 후보화
- MBC 드림센터 (고양): 방송 제작 시설. 외부 촬영·대관은 별도 허가 확인 전 추천 장소로 확정하지 않음
- KBS 별관·공개홀 등 방송 시설: 시설별 일반인 접근·촬영 허가를 확인한 경우에만 등록
- 민간 대형 렌탈 스튜디오: 실제 상호·주소·공간 사진·대관 조건을 검증한 뒤 개별 등록 (상호 미확인 상태에서 임의 생성 금지)

### 공연장·무대 공간 — 공연장 내부 촬영은 사전 허가 확인
- 예술의전당 (서울): 대형 공연·전시 시설, 외부 공간과 건축 프레임
- 국립극장 (서울): 공연예술 공간, 계단·광장·건축 외관
- 세종문화회관 (서울): 도심 대형 공연장과 광화문 도시 배경
- LG아트센터 서울 (서울): 현대 건축·로비 공간
- 블루스퀘어 (서울): 공연·도시적 외관
- KT&G 상상마당 홍대 (서울): 공연·문화 공간, 공간별 촬영 정책 확인
- 성수아트홀 (서울): 공연장 및 지역 산업 공간 맥락

## 등록 전 필수 확인
1. 214곳 원본 및 현재 2.0 데이터와 이름·주소·좌표를 대조해 중복 제거.
2. 장소의 실제 존재·운영 상태를 공식 사이트로 확인.
3. 대표 이미지는 해당 장소와 일치하는지 확인하고 출처·이용 조건 기록. 임의 이미지나 검색 썸네일을 확정 사진으로 사용하지 않음.
4. 일반 방문 가능 여부와 상업 촬영 허가를 분리해 기록.
5. 스튜디오·공연장 내부는 외부에서 촬영 가능하다고 추정하지 말고 대관·허가를 확인.
6. 각 후보에 ‘촬영 가치’와 구체적인 시각적 근거를 기록하고 관광지만으로는 등록하지 않음.

## 다음 재개 지점
2.0 장소 데이터 파일 및 구버전 214곳 원본을 사용할 수 있게 된 뒤, 이 후보 목록과 실제 데이터의 중복·누락 대조를 실행한다. 그때까지 후보를 운영 데이터에 자동 삽입하지 않는다.
