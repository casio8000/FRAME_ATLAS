# FRAME ATLAS 2.0 — 이미지 조사·등록 기준

## 목적

이미지가 없는 장소를 줄이는 동시에, 다른 장소의 사진이나 재사용 권한이 불명확한 사진이 대표사진으로 잘못 들어가는 일을 줄인다. 검색량만 늘리는 방식이 아니라 후보 수집 → 검토 → 승인 → 장기 보관의 흐름을 만든다.

## 이미지 검색원

각 장소에서 아래 경로를 병행한다.

1. Openverse 자동 검색 — 공개 라이선스가 명시된 이미지 검색
2. Wikimedia Commons API 자동 검색 — 파일 제목·미리보기·설명 페이지·메타데이터 수집
3. Google 이미지 — 폭넓은 웹 이미지 탐색
4. Bing 이미지 — 다른 색인의 교차 확인
5. 네이버 이미지 — 국내 블로그·언론·지역 정보 탐색
6. 다음 이미지 — 국내 검색 결과 교차 확인
7. Flickr — 작가 사진과 라이선스 정보 탐색
8. 공식 홈페이지·지자체·공공 관광 정보 — 시설의 실제 모습과 공식 사진 확인
9. 필요에 따라 박물관·문화재·공원 운영기관 및 지역 관광 사이트를 추가한다.

Google/Bing/Naver/Daum/Flickr의 페이지를 자동 스크래핑하는 대신 검색 페이지를 연다. 앱 내 자동검색은 공식적으로 조회 가능한 API를 우선 사용한다. 새로운 API를 붙일 때는 이용조건·요청 제한·출처표시 조건을 확인한다.

## 후보마다 기록할 필드

- 이미지 직접 주소
- 원본 설명 페이지
- 출처 사이트와 저작자/사진가
- 라이선스 명칭 및 근거 URL 또는 명시적 사용 허가 근거
- 실제 장소 일치 상태: 미확인 / 확인 / 불일치
- 구도: 현장 시점 / 장소 전경 / 실내 / 디테일 / 항공·드론 / 지도·포스터
- 후보 상태: 후보 / 승인 / 제외
- 검토 메모 및 검토일

## 대표사진 승인 조건

대표사진으로 승인하려면 다음 조건을 모두 충족해야 한다.

- 사진이 해당 장소와 일치함을 실제로 확인했다.
- 원본 페이지를 기록했다.
- 사진 사용 권한이 확인됐고 근거 링크나 증빙이 있다.
- 작가/저작자와 요구되는 출처표시를 기록했다.
- 검색용 썸네일이나 항공사진이 장소 대표사진으로 잘못 사용되지 않도록 구도를 확인했다.

앱의 선택 필드는 법률적 검증을 자동으로 대신하지 않는다. CC BY는 저작자 표시가 필요하고, CC BY-SA는 동일조건변경허락 등 해당 라이선스 조건을 따르는지 확인한다. 비상업용 라이선스(CC BY-NC 등)는 공개된 앱에서의 사용 목적과 조건을 별도 검토하지 않은 채 승인하지 않는다.

## 이미지 저장 정책

- 검토 중인 사진은 후보 URL/원본 페이지로 관리하고 정식 대표 이미지와 분리한다.
- 공개 재사용 권리가 확인된 이미지, 직접 촬영한 이미지, 명시적 허가를 받은 이미지만 저장소 내 이미지 파일로 복사한다.
- 사진 파일을 저장할 때는 파일 경로, 출처 페이지, 저작자, 라이선스, 다운로드·검토일, 이미지 해시를 함께 보관한다.
- 출처 링크가 있다는 사실만으로 재사용 권리가 확보된 것은 아니다.
- 공개 GitHub 저장소에 업로드된 사진은 앱 사용자 외의 사람에게도 공개될 수 있다.

## 현장·촬영 실용성 기준

대표사진은 가능하면 일반 방문자의 눈높이에 가까운 지상 시점 사진을 우선한다. 장소 식별에 도움이 되는 건물 외관, 길·계단·벽·수변·구조물 등 실제 촬영 배경이 포함된 사진을 우선하고, 항공 전경·포스터·지도는 대표사진이 아니라 참고 이미지로 분류한다.

사진만으로 촬영 허가를 판단하지 않는다. 일반 방문 가능 여부, 삼각대/조명 등 장비 사용, 상업촬영 허가, 입장료, 운영시간, 주차, 장비 반입은 별도 출처로 확인한다.
