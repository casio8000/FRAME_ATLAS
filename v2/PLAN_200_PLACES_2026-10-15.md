# FRAME ATLAS 2.0 — 200개 장소 확장 검토 계획

## 0. 개정된 진행 순서: 1차 14곳 → 단계적으로 200곳

- 1차 조사 14곳은 핵심 카탈로그에 등록했습니다. 이어서 한국적 재료감과 글로벌 에디토리얼에 적합한 예술·건축 장소 15곳을 `v2/data/art_locations_curated_20261016.json` 보조 목록에 추가했습니다. 앱이 해당 파일을 읽으면 ID 중복 없이 화면의 166곳으로 합치며, 이후 GitHub 동기화·게시 시 핵심 카탈로그로 통합됩니다.
- 현재 카탈로그에 이미 존재하는 reviewQueue 14건은 별도 자료입니다. 그중 일부는 이미 기존 장소와 연결/병합되어 있으므로 신규 장소 14곳으로 그대로 계산하지 않습니다.
- **현재 14곳은 1차 조사 레코드이지, 최종 추천 확정이 아닙니다.** 실제 장소 사진·출처·중복·운영·촬영 허가·사진 이용권을 확인하고 기준 미달은 보류 또는 제외합니다.
- 1차 묶음이 끝나면 결과와 지역·공간 유형의 부족을 기준으로 다음 약 15곳 묶음을 정하고, 검증과 배포를 반복해 200곳으로 확장합니다.
- 핵심 `places.json`에는 151개 레코드가 있고, 새 앱에서는 보조 예술·건축 목록 15곳을 추가로 불러와 화면상 166곳이 됩니다. 다음 ‘GitHub 동기화·게시’가 성공하면 보조 목록의 장소도 핵심 카탈로그에 병합됩니다. 품질 감사에서 일부가 통합·보류될 수 있으므로 200곳은 **사진가에게 실제로 추천할 수 있는 장소 수**를 기준으로 관리합니다.

## 1. 현재 상태와 목표

- 화면상 카탈로그: **166개 장소**(핵심 카탈로그 151 + 예술·건축 보조 자료 15)
- 별도 검토 대기 큐: **14개 후보**(카탈로그와 별도)
- 단순 산술 목표: 166 + 34 = 200. 이는 현재 166곳을 모두 유지하는 경우에만 성립합니다.
- 앱이 보조 파일을 읽지 못하거나 품질 감사에서 장소가 보류·통합·제외되면, 화면 수와 남은 조사 수를 다시 계산합니다.

**원칙: 숫자를 맞추기 위해 약한 관광지를 추가하지 않습니다.** 200개 레코드와 실제 사진작가에게 추천할 수 있는 검증 완료 장소 200곳을 구분합니다.

## 4. 활성 추천 등록 전 필수 확인

1. 정확한 장소명, 시·도, 주소 또는 지도에서 찾을 수 있는 세부 구역.
2. 공식 운영기관·설계사·공공기관·신뢰할 수 있는 관광기관 중 최소 한 곳의 근거 링크.
3. 사진 원문과 장소가 실제로 일치하는지 확인. 다른 지점·관광 포스터·지도·항공사진을 대표사진으로 쓰지 않음.
4. 사진 이용권/라이선스와 장소에서의 촬영 허가를 별도로 기록. 불명확하면 ‘미확인’으로 둠.
5. 운영 종료·공사·휴관·접근 제한 여부 확인. 확인된 제한은 추천 노출에 반영.
6. 화면상 166개 장소(핵심 자료와 예술·건축 보조 파일 병합), 별칭, 세부 구역, 이전 버전 목록과 중복 검사.
7. 왜 예술적 촬영에 가치가 있는지 구조·빛·질감·원근·구도·배경·인물 활용도를 근거로 설명.
8. 현장 정보는 확인 날짜를 기록하고, 미확인 주차·비용·전원·촬영 가능 여부를 단정하지 않음.

### 1단계 — 기존 목록 품질 감사
- 화면상 166개 장소의 이름/별칭, 실제 위치·참고 이미지 일치, 예술적 촬영 활용성을 단계적으로 점검. 새 15곳은 예술·건축 공간 보충 목록이며 상세 메모는 사용하면서 보완합니다.
- 14개 검토 대기 후보는 별도 큐로 유지하고 기준 통과 전 활성 장소 수에 합산하지 않음.
- 구버전 214개 목록에 접근할 수 있으면 먼저 누락된 가치 있는 후보를 대조하되, 같은 장소의 세부 구역 중복 등록 방지.

### 2단계 — 충분한 후보 풀 확보
- 화면상 남은 산술 수는 34개지만 탈락·통합을 고려해 약 55~70개를 조사 대상으로 모음.
- 스튜디오·공연장·산업유산·현대건축·역사 로케이션·자연형 후보를 지역별로 균형 있게 조사.
- 각 후보마다 공식 출처, 사진 원문, 중복 여부, 상업 촬영 허가 상태를 기록.

### 3단계 — 15개 안팎으로 나눠 추가
- 첫 14개 레코드의 출입·운영·사진·허가 검증 및 화면 표시를 점검한 뒤 다음 약 15개 조사 묶음으로 진행.
- 각 묶음마다 중복 ID·장소명, 이미지 경로, 사진 로딩, 검색/필터, 상세 진입/목록 복귀, PC·모바일 레이아웃을 검사.
- 검색 결과를 자동으로 대표사진 지정하거나 검증 전 데이터를 묶음째 게시하지 않음.

## 7. 계속 지킬 원칙

200이라는 숫자보다 정확한 장소, 실제 사진, 촬영 가치가 우선입니다. 사진을 찾지 못하면 임의 이미지나 다른 장소 사진을 쓰지 않습니다. 장소 정보·사진 후보·사진 사용권·현장 촬영 허가는 서로 다른 상태로 기록합니다. 기능을 변경할 때는 사용자 매뉴얼과 작업 체크포인트를 함께 갱신합니다.
