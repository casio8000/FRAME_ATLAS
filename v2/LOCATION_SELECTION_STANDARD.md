# FRAME ATLAS 2.0 — 사진가 관점의 장소 선정 기준

## 앱의 목적

FRAME ATLAS는 관광지 인기순위가 아니라, 패션·인물·예술·브랜드·에디토리얼 촬영에서 시각적으로 독창적인 결과물을 만들 수 있는 실내·야외 로케이션을 찾는 도구다.

방문객 수, SNS 인증 사진 수, 유명세, 단순한 랜드마크 여부는 예술적 촬영 잠재력 점수에 반영하지 않는다. 유명한 곳도 공간 자체의 조형성이나 배경·빛의 활용 가능성이 구체적으로 설명될 때만 후보로 둔다. 덜 알려진 공간이라도 독특한 선·질감·빛·구도·배경 다양성을 제공하면 우선순위를 높인다.

## 사진 잠재력 100점 체계

| 항목 | 배점 | 검토 질문 |
|---|---:|---|
| 시각적 고유성 | 30 | 해당 장소만의 공간·구조·색·형태·질감이 있는가? |
| 구도·촬영 각도 다양성 | 20 | 와이드·미디엄·디테일, 전경·중경·배경을 다양하게 구성할 수 있는가? |
| 빛·그림자·재료 질감 | 20 | 시간대·자연광·인공광·반사·그림자로 사진적 해석이 가능한가? |
| 패션·인물·예술 에디토리얼 활용도 | 20 | 단순 기념사진을 넘어 콘셉트와 서사를 가진 결과물을 만들 수 있는가? |
| 실내외·날씨 유연성 | 10 | 실내외가 연결되거나 계절·날씨에 대응할 배경이 있는가? |

- A (85–100): 최우선 조사
- B (74–84): 유망한 보완 조사
- C (0–73): 조건부·후순위. 보완 가치가 낮으면 후보에서 제외한다.

이 점수는 장소 설명과 공개된 사진을 기준으로 한 **탁상 기획 평가**다. 현장 실측이나 촬영 결과를 입증하지 않는다. 장소별 점수 근거·이미지 후보·검토일이 쌓이면 평가를 재조정한다.

## 예술적 잠재력과 제작 가능성을 분리한다

아래는 별도 검증 필드로 관리한다. 사진 잠재력이 높더라도 이 정보가 확인되지 않으면 실제 촬영을 확정할 수 없다.

- 시설 운영 여부, 폐쇄·공사·행사 등 변동
- 방문객에게 허용된 구역과 촬영 가능한 각도
- 삼각대·조명·반사판·장비 반입 여부
- 인물·패션·상업 촬영의 사전 승인, 대관 신청, 비용
- 주차·하차·장비 운반·화장실·대기 공간
- 시간대·혼잡도·빛의 방향·우천 대안
- 사진의 실제 장소 일치, 출처·저작자·재사용 라이선스

예: 공간 자체가 사진적으로 뛰어난 산업유산이라도 실내가 대관 전용이거나 상업촬영 사전 승인을 요구할 수 있다. 이런 제약은 사진 잠재력 점수를 낮추기보다 제작 가능성 필드에 명확히 기록한다.

## 장소 후보 선정 게이트

다음 중 최소 한 가지 이상이 뚜렷하지 않은 장소는 단지 유명 관광지라는 이유만으로 신규 등록하지 않는다.

- 독특한 건축·기하학·공간 구조
- 산업유산·작업장·도시의 재료감
- 미술·조형물과 자연 공간의 조합
- 독특한 실내 공간, 자연광 또는 인공광
- 의미 있는 그림자·반사·색 대비·반복 패턴
- 패션·인물·예술 에디토리얼에 유효한 서로 다른 배경

관광 명소도 이 기준을 만족하는 특정 구역이나 촬영 포인트가 있을 때만 해당 범위로 제한하여 등록한다.

## 사진 검증 기준

각 장소별로 서로 다른 목적의 이미지를 탐색한다.

1. 실제 공간 확인용 전경/시설 사진
2. 사진가가 참고할 수 있는 인물·패션 에디토리얼 구도
3. 건축·기하학·질감·그림자 사진
4. 실내/자연광/야외 촬영 대안
5. 디테일·작은 공간·작품별 사진

Openverse와 Wikimedia Commons의 자동 검색뿐 아니라 Google, Bing, 네이버, 다음, Flickr, 공유마당, 한국관광공사, 지자체·시설 공식 사이트를 병행한다. 검색원마다 자동화 가능 범위와 재사용 권리가 다르므로, 검색 결과는 후보일 뿐이다.

대표사진은 실제 장소 일치, 원본 페이지, 작가/저작자, 공개 사용 권리와 해당 조건을 확인하고, 허용된 이미지를 저장소 안에 파일로 보관한 뒤 승인한다. 확인되지 않은 사진은 개인 조사 후보로만 두며 공개 대표사진으로 표시하지 않는다.
