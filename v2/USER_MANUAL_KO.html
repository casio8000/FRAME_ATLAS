FRAME ATLAS · 2.0

USER GUIDE / FIELD SCOUTING

사용자 매뉴얼

전국의 촬영 장소를 사진가의 관점에서 탐색하고, 실제 장소 사진과 촬영 조건을 확인·기록하기 위한 안내서입니다.

PC에서는 장소 조사와 데이터 관리를, 모바일에서는 현장 확인과 빠른 장소 탐색을 중심으로 사용하도록 구성합니다.

1. 먼저 알아둘 점

저장 범위 주의
현재 버전의 ‘저장’은 기본적으로 이 브라우저의 작업 초안에 저장됩니다. PC에서 입력한 내용이 iPhone에 자동으로 즉시 나타난다고 가정하지 마세요. 장소 카탈로그를 GitHub에 게시하는 기능과 사진 파일을 저장소에 업로드하는 기능은 서로 다릅니다. 사진 파일 업로드·다른 기기 동기화는 별도로 검증해야 합니다.

장소 사진은 후보일 수 있습니다. 사진이 보인다는 사실만으로 해당 장소와 일치하거나 촬영 허가를 받은 사진이라는 뜻은 아닙니다.

2. 여섯 화면 사용법

주요 메뉴는 시안의 4개 탭입니다. 홈 · 지도 · 저장 · 더보기. 전체 아카이브와 사진 후보(갤러리)는 더보기/마이페이지에서 들어갑니다. 이 구조로 스플래시, 홈, 장소 상세, 지도, 사진 후보, 마이페이지의 여섯 화면을 이용합니다.

01 · 스플래시 / 시작 화면

앱을 열면 FRAME ATLAS 소개 화면이 나옵니다. 시작하기 또는 메인 화면 둘러보기를 눌러 장소 목록으로 이동합니다.

02 · 메인 화면

장소 검색창에 장소명·지역·촬영 분위기를 입력하고 전국 필터를 사용합니다. 장소 카드를 누르면 해당 장소 상세 화면으로 이동합니다. 장소 카드는 관광지 인기도보다 건축의 조형성, 질감, 빛, 배경 다양성 등 사진적 가능성을 살펴보기 위한 목록입니다.

03 · 장소 상세 정보

대표/참고 사진, 장소 설명, 사진 잠재력 점수, 사진 후보, 공식 출처 및 확인 상태를 살펴봅니다. 주소와 촬영 허가가 미확인이라면 촬영 확정 전에 공식 홈페이지나 관리 부서에 확인합니다. 현장 촬영 체크리스트에 주차·장비 반입·접근성·전원·탈의 공간·촬영 제한 등을 입력하고 저장할 수 있습니다.

04 · 지도 / 길찾기

지역 필터와 장소 목록을 이용해 지도를 확인합니다. 지도 서비스가 표시하는 위치는 검색 결과일 수 있으므로 출발 전 주소와 출입구를 다시 확인합니다.

05 · 사진 후보

장소별 후보를 비교합니다. 장소와 일치하는지, 촬영 각도가 맞는지, 원문 링크와 이용 조건이 있는지 확인한 뒤 대표사진으로 선택합니다. 다른 장소의 사진이나 항공·드론 사진이 일반 촬영 참고사진에 섞이지 않도록 주의합니다.

06 · 마이페이지

저장 장소, 아카이브, 사진 후보, 백업 내보내기/가져오기, 설정과 이 매뉴얼을 이용합니다.

이전 버전 스카우팅 기록의 이관

기존 FRAME ATLAS 데이터의 장소명이 정확히 일치하는 11개 장소(문화비축기지, 선유도공원, 세운상가, 성수동·문래동, 문화역서울284, 인천아트플랫폼, 개항장, 배다리, 미메시스, 수원 행궁동)에 한해 이전 버전의 창작/제작 적합성 점수, 추천 촬영 시간대, 렌즈·앵글, 광원·배경 제안, 장비·주차·전원, 위험·허가 체크리스트를 ‘이전 버전 스카우팅 기록’으로 보존했습니다. 기록의 날짜와 출처를 함께 표시하며, 현재 운영·촬영 허가·비용이 확인된 사실로 취급하지 않습니다. 새로 확인한 결과는 아래 현장 촬영 체크리스트에 기록하세요.

4. 사진 추가와 대표사진 선택

  1. 상세 화면에서 사진 추가 / 교체로 이동합니다.
  2. 직접 이미지 URL을 넣거나 사진 파일을 선택합니다. URL이 있다고 해서 이미지가 저장소에 복사되는 것은 아닙니다. 웹 주소에서 표시되는 참고사진과 실제 GitHub에 저장된 이미지 파일은 다른 상태입니다. 파일 저장이 필요한 사진은 실제 파일을 선택해 추가하고, 이용 권리·장소 일치 정보를 확인한 뒤 GitHub 게시 기능으로 업로드해야 합니다.
  3. 사진 설명·구도·원문 링크·장소 일치 여부를 입력합니다.
  4. 저장된 후보 중에서 대표사진으로 사용을 선택합니다. 실제 장소와 일치하지 않으면 대표사진으로 지정하지 마세요.
  5. 저작권과 사용 조건을 확인합니다. 웹에서 볼 수 있다는 이유만으로 화보·상업 촬영에 재사용할 수 있는 것은 아닙니다.
사진이 표시되지 않으면 원문 페이지에서 이미지가 살아 있는지 확인하고, 직접 이미지 주소인지 점검합니다. 사진 원문 링크와 직접 이미지 주소는 다를 수 있습니다.

5. 저장·백업·게시

이 기기에 임시 저장

장소 정보와 체크리스트를 저장하면 브라우저의 로컬 작업 초안에 반영됩니다. 브라우저 데이터 삭제·기기 교체·비공개 모드 사용 시 작업을 잃을 수 있으므로 중요한 수정 전후로 JSON 백업을 내보내 보관하세요.

JSON 백업

  1. 마이페이지에서 백업 내보내기를 선택합니다.
  2. 파일을 날짜와 함께 PC의 별도 폴더에 보관합니다.
  3. 복원이 필요하면 백업 가져오기를 사용하되, 현재 자료를 먼저 내보내 별도 보관합니다.

사진 파일을 GitHub에 저장하기

장소 상세 화면에서 사진 파일을 선택해 후보로 추가한 뒤, 이용 권리와 장소 일치 여부를 확인합니다. 개인 기기의 임시보관 상태는 이 기기에서만 사용될 수 있습니다. 다른 기기에서도 같은 이미지 파일이 필요하다면 저장 가능한 권리가 확인된 파일을 GitHub 게시 기능으로 올린 후, 카탈로그와 파일 경로가 맞는지 확인합니다.

GitHub 게시

게시 기능은 장소 카탈로그 JSON을 GitHub 저장소에 반영하는 작업입니다. 토큰을 입력하기 전 저장소와 권한을 확인하고, 신뢰하는 개인 기기에서만 진행하세요. 게시 성공 뒤에도 GitHub Actions의 Pages 배포가 완료됐는지 확인하고 새로고침합니다.

현재 앱에서 사진 파일이 저장소에 업로드되거나 여러 기기 간 개인 기록이 자동 병합된다고 보장할 수 없습니다. JSON 카탈로그 게시와 이미지 파일 저장은 별도 기능입니다.

6. 자주 발생하는 문제

수정 사항이 보이지 않음

  • 2.0 주소가 /FRAME_ATLAS/v2/index.html인지 확인합니다. 루트 주소는 이전 버전입니다.
  • PC에서는 Ctrl + F5로 강력 새로고침합니다.
  • 홈 화면 아이콘으로 실행한 앱은 오래된 서비스 워커 캐시를 사용할 수 있습니다. 브라우저에서 사이트를 다시 열고 최신 화면을 확인합니다.
  • GitHub 저장소의 최신 커밋과 Pages 배포 상태가 일치하는지 확인합니다.

장소 사진이 안 나옴

  • 후보 URL과 원문 페이지를 확인합니다.
  • 원문이 차단되거나 삭제되었으면 다른 후보를 검색합니다.
  • 다른 장소의 사진을 대신 표시하지 말고, 사진 미확인 상태를 유지합니다.

다른 기기에서 데이터가 다름

로컬 초안은 브라우저·기기별로 다를 수 있습니다. 백업을 먼저 만들고, 게시/복원 전에는 원본 JSON을 보존합니다. 동기화가 성공했다고 표시되어도 실제 항목 수와 사진 표시를 확인합니다.

7. 장소 조사 원칙

  • 유명 관광지라는 이유만으로 촬영 장소로 채택하지 않습니다.
  • 구조·재료·빛·그림자·구도·배경 다양성·실내외 활용성을 평가합니다.
  • 주소, 운영 상태, 사진 일치, 촬영 허가, 비용, 접근성에는 확인 날짜와 출처를 남깁니다.
  • 공식 확인 전에는 촬영 가능·주차 가능·전원 사용 가능 등으로 단정하지 않습니다.
  • 사진 후보의 장소 일치와 사용 권한은 서로 다른 확인 항목입니다.
FRAME ATLAS 2.0 · 개인 촬영 장소 조사 도구 · 사용자 매뉴얼은 실제 기능 검증 결과에 따라 갱신합니다.

매체 노출·촬영 이력 확인

장소 상세 화면의 ‘매체 노출·촬영 이력’에는 작품명, 매체·제작사, 공개일 또는 방영일, 장면·공간 설명과 근거 링크가 확인된 경우에만 표시됩니다. 건축 기사나 장소 소개 콘텐츠는 영화·드라마·광고 촬영 이력과 구분하며, 공식 자료에 작품명이 없으면 임의로 추정하지 않습니다.
