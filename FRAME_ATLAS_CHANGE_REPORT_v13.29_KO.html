FRAME ATLAS 3.0 v13.29 — 티맵 실제 길찾기 수정

작업일: 2026-10-29 · 기준본: Library에서 복원한 v13.28

원인

티맵 버튼이 목적지 좌표 없는 앱 검색 URL 또는 잘못된 경로 매개변수를 사용해 티맵의 시작/홈 화면으로 빠질 수 있었습니다. 장소 좌표가 대부분 저장되어 있지 않아 단순히 URL만 바꾸는 수정으로는 부족했습니다.

수정

  1. 정식 경로 파라미터 rGoName(목적지명), rGoX(경도), rGoY(위도)를 사용합니다.
  2. 등록·캐시 좌표가 없으면 장소명과 주소로 좌표를 조회하고, 좌표를 얻은 경우만 경로를 요청합니다.
  3. 조회 실패 시 홈페이지나 검색 URL로 우회하지 않고 원인을 안내합니다.
  4. PC에서 티맵 홈페이지를 열지 않고 모바일 티맵 연결을 안내합니다.

검수

티맵 URL/control-flow 검사 5/5, 정적 검증 통과 (JavaScript 18개·인라인 스크립트 3개·JSON 24개·CSV 32개/5,125행). 실제 iPhone 티맵 앱 실행과 경로 개시는 검증되지 않았습니다. GitHub/Cloudflare 게시 전 상태입니다.
