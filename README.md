# FRAME ATLAS v5.36 — PRO PHOTO LOCATION SCOUT

개인용 사진촬영 로케이션 스카우팅 프로그램입니다. `index.html`과 `data/places.js` 외에 `data/review-workflow.js`가 위치·사진·허가·현장 기술 검증 기록의 입력·저장·내보내기를 담당합니다.

## 핵심 기능 및 검증 원칙
- 장소 레코드 수는 계속 변경되므로 현재 수량은 `tools/validate.py` 실행 결과와 `tools/report.md`를 기준으로 확인합니다.
- 장소 상세 화면에 **검증 워크스페이스**를 추가해 실제 주소·정밀 좌표·진입점·답사일, 사진 일치·출처·이용권, 상업촬영 허가 근거·확인일을 직접 기록할 수 있습니다.
- 정밀 좌표로 승인 저장하려면 한국 범위의 위도·경도, 출처 URL, 확인일이 필요합니다. 승인 또는 허가 불필요로 기록할 때는 공식/서면 근거 URL과 확인일이 필요합니다.
- 현장 실측 촬영 포인트 3개와 빛·장비 반입·전력·주차·대기공간·안전·날씨 대안을 별도 기록합니다. 기존 촬영 포인트 설명은 현장 실측을 뜻하지 않습니다.
- 품질 대시보드에서 자료 완성도, 기획상 창작/제작 적합도, 현장 준비도, 검증 신뢰도를 분리해 확인하고 현황 CSV를 내려받을 수 있습니다.
- 사용자 검증 기록은 `faReview57_<ID>` 키로 기기 저장되며 JSON 백업 및 GitHub 백업·동기화 대상에 포함됩니다.
- PWA 서비스 워커가 앱 셸, 장소 데이터, 검증 워크플로 파일을 same-origin 캐시합니다. 외부 이미지·지도·검색 API는 오프라인 보장 대상이 아니며 온라인 첫 실행이 필요합니다.

## 실행 및 배포
1. 앱은 저장소 루트의 `index.html`을 기준으로 열립니다. GitHub Pages 주소는 `https://casio8000.github.io/FRAME_ATLAS/`입니다. 브라우저의 로컬 파일 정책에 따라 일부 기능(서비스 워커, 외부 요청)이 제한될 수 있습니다. 완전한 PWA/오프라인 테스트는 GitHub Pages 또는 localhost 같은 HTTP(S)에서 진행하세요.
2. 이 저장소는 이미 `index.html`, `data/`, `assets/`, `sw.js`가 루트 기준으로 구성되어 있습니다. 추가 배포 시 하위 폴더가 한 겹 더 생기지 않도록 주의하세요.
3. 업데이트 전에 앱의 DB 백업/복원 메뉴에서 사진·메모·후보·촬영 건을 백업하세요. 검증 기록도 백업 파일 및 GitHub 백업 키에 포함됩니다.
4. 저장소 루트에서 `python tools/validate.py` 와 `python tools/check_app.py` 를 실행합니다. GitHub Actions에서도 push/PR마다 자동 점검하며, 검증 경고는 데이터 결함 가능성 또는 현장 확인 공백을 나타냅니다.

## 데이터 신뢰 원칙
- 장소 수량은 고정값으로 문서에 복사하지 않고 자동 검증 결과를 기준으로 합니다.
- 신규 12곳과 기존 장소 모두, 현장 실사·정밀 GPS·대표 사진 일치·상업촬영 승인이 자동으로 완료된 것은 아닙니다.
- 장소 일치 사진 확인과 이미지 이용권은 독립 항목입니다.
- 일반 관람 가능과 상업촬영 허가는 다릅니다. 승인 상태는 날짜가 있는 공식/서면 근거를 기록해야 합니다.
- 점수는 네 가지를 구별합니다: 자료 완성도, 창작 적합도, 기획상 제작 적합도, 현장 준비도 및 검증 신뢰도. 어떤 점수도 법적 허가나 현장 안전을 보증하지 않습니다.
