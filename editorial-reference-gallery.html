출처 기록과 공간·빛·재료의 관련성을 기준으로 선정한 참고 사례입니다. 현재 등록된 장소에서 촬영한 사진이라는 뜻은 아닙니다. 사진 카드는 고정된 4:3 박스에 표시하고, 카드 하단에서 발행처 원문과 추가 검색을 따로 선택할 수 있습니다.

② ADDITIONAL IMAGE SEARCH

추가 후보 검색 · Google / 네이버 / Bing

이 영역은 더 많은 비슷한 이미지를 찾는 검색 결과입니다. 검색 결과는 직접 선별된 대표 화보가 아닙니다. 실제 배경·장소·사진가·출처와 사용 조건을 확인한 후 참고하세요.

중요: 대표사진 미리보기는 외부 발행처 이미지 주소로 표시합니다. 주소나 CDN이 차단되면 다른 이미지 주소를 자동 시도하고, 모두 실패하면 사진 박스를 유지한 채 Google·네이버·Bing 검색 경로를 제공합니다. 별도 검색 결과는 앱의 대표사진으로 자동 등록하지 않습니다.
