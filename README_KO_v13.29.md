# FRAME ATLAS 3.0 v13.29

## 실행 패키지
- 현재 프로그램 버전: v13.29
- 기준 패키지: Library에 저장된 v13.28
- GitHub/Cloudflare 게시: 미게시

## 티맵 길찾기 수정
티맵 버튼은 홈페이지를 열지 않습니다. 목적지 좌표가 있으면 `tmap://route?rGoName=목적지명&rGoX=경도&rGoY=위도`를 사용합니다. 좌표가 없으면 장소명과 주소로 좌표를 조회하고, 조회가 실패하면 홈페이지 대신 안내를 표시합니다. PC에서는 네이버 지도, 모바일에서는 티맵 앱을 사용하도록 안내합니다.

## 실행
Windows에서는 `start_local_preview.bat`를 실행합니다. Python 설치는 필요하지 않습니다.

## 업데이트 전후
더보기에서 현재 기기의 개인 기록을 JSON으로 백업한 뒤 프로그램을 교체하세요. ZIP은 프로그램 소스·데이터 백업이며 PC와 iPhone의 개인 메모는 자동 동기화하지 않습니다.

## 게시 후 확인
iPhone Safari에서 앱을 새로고침한 뒤 티맵 버튼을 눌러 실제 티맵 앱이 열리는지, 올바른 장소와 촬영 진입점을 안내하는지 확인합니다. 주소 지오코딩 결과는 정문·주차장과 다를 수 있습니다.
